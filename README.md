🚀 Cards of Legends — Update v0.8.0
✨ New Features & Combat Feel
Procedural Audio Engine: Added a custom Web Audio API sound system with synthesized effects for card plays, attacks, shields, healing, shop purchases, and UI clicks—with zero external audio files required and a new SFX toggle in the top HUD.

Attack Lunges & Impact Flashes: Heroes and enemies now dash forward when striking and flash on impact, making turn sequences feel much punchier.

Floating Combat Numbers: Added color-coded popups for damage (-18), big hits (-24 💥), shields (+12 🛡️), and healing (+6 ❤️) with smart staggering for multi-hit attacks.

Live Card Stat Previews: Hand card descriptions now recalculate dynamically in real time based on Strength/Dexterity buffs, Relics, Rest Bonus Turns, Vulnerable targets, and active Hemorrhage stacks—highlighting boosted stats in green with hover breakdown pills.

🛠️ Bug Fixes & Display Improvements
MacBook Retina (2x DPI) Canvas Fix: Fixed a high-DPI scaling bug where Retina displays doubled canvas coordinates, cutting off the hero sprite and pushing enemies off-screen.

Responsive Battle Viewport: Updated the battle screen layout (100dvh) so the top HUD, Action Sequence bar, and bottom VAULT / SCRAP card buttons fit cleanly on 13"–14" laptops and embedded frames without clipping.

Hosting & Asset Stability: Standardized script casing for case-sensitive web servers (like GitHub Pages) and added a browser tab favicon.
